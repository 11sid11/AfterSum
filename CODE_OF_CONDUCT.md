# Code of Conduct

AfterSum should be a useful, respectful place to build software together.

## Expected behavior

Contributors and maintainers are expected to:

- discuss ideas and disagreements with respect;
- focus criticism on code, design, behavior, and evidence rather than people;
- welcome contributors with different levels of experience;
- avoid harassment, discrimination, threats, personal attacks, and deliberately disruptive behavior;
- protect other people's privacy, especially when issues involve financial or personal data.

## Unacceptable behavior

Harassment, discriminatory language, doxxing, sexualized attention, intimidation, repeated bad-faith disruption, or publishing another person's private information is not acceptable in project spaces.

## Reporting

If a conduct issue can be handled publicly, contact the repository maintainer through the relevant GitHub discussion or issue. For sensitive matters, contact the maintainer privately through their GitHub profile rather than posting personal details publicly.

Maintainers may edit, hide, reject, or remove contributions and may restrict participation when behavior materially harms the project or its community.

## Scope

This applies to issues, pull requests, reviews, discussions, and other spaces where someone is representing the AfterSum project.
